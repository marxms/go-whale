# Branding

GoWhale is the product name. The repository and Go module are **go-whale**; the
binary is **gowhale**. Keep those three spellings distinct.

are quality-90 derivatives used by the README and documentation; they are the
same mark, not a variant. The SHA-256 checksums are recorded in the launch
evidence.
